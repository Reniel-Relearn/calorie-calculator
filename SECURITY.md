# Security Policy

## Supported release

CalorieCheck Version 2 is under active development. Security fixes apply to the current `main` branch and the publicly deployed staging application.

## Report a vulnerability privately

Do not open a public issue with exploit details, credentials, private user data, or reproduction tokens.

Use GitHub's private vulnerability reporting page:

https://github.com/Reniel-Relearn/calorie-calculator/security/advisories/new

Include the affected URL or component, a concise impact description, safe reproduction steps, and whether any credential or personal data may have been exposed. Replace real personal information with synthetic examples and revoke any token that was copied into a report.

## Response expectations

The maintainer will acknowledge a usable report when account access permits, assess severity, contain active exposure, prepare a fix on a review branch, and publish details only after remediation. This free-tier demo does not promise a service-level response time or a bug bounty.
